## 线路和 IP 属性，比几核几 G 更能决定这台机器能不能用

买英国 VPS 的人里，很大一部分最后发现买错了，问题不在配置，在 IP 属性。

VPS 的 IP 大致分三档。机房 IP 最便宜，也最容易被平台识别，TikTok、Netflix、ChatGPT 后台都有 IP 库，机房段直接打标。原生 IP 指 IP 归属地和机房所在地一致，比纯机房 IP 好一点，本质仍是数据中心属性。住宅 IP 来自英国本土家宽运营商（BT、Sky、Virgin Media 这类），在平台数据库里登记的就是“住宅”。双 ISP 是再往上一层：机器同时接入两家本土 ISP，IP 段在两家之间广播，纯净度更高，批量封号时不容易被误伤。

CstoneCloud 和 LisaHost 主打的都是这一类。CstoneCloud 英国线的路由，测评记录给的是：电信去程绕美国走 GTT，联通去程绕德国走 Level3，移动去程绕德国走 GTT，国内直连延迟 200ms 往上。这是国际 BGP 的正常表现，商家自己也建议自备中转。所以它的正确用法是当落地机，前面挂香港或日本的中转。

Infrawire 伦敦 LD5 的路由是另一套：电信去程经荷兰到英国接 RETN、回程 RETN；联通去程绕美国走 Lumen、回程 RETN；移动去程绕德国走 RETN、回程 RETN。也是绕，只是绕的路径不同。

666Clouds 的英国线是三网回程优化，移动去程 CMIN2、联通去程 AS9929，但电信上传那段仍是普通线路，这条容易被“优化线路”四个字盖过去。

AkkoCloud 伦敦线的回程是电信、联通走 CTG/CN2 GIA，移动走 CMIN2；去程电信走 CN2（59.43 段），联通和移动各走自己的优化骨干。一份测评记录的三网平均延迟在 167ms 左右（电信 169ms、联通 167ms、移动 163ms），这是该测评者本地网络的口径，你那边不一定一样。想验证就自己 ping 一遍。

对国内用户来说，结论并不复杂：要低延迟直连，选回程有 CN2 GIA 或 CMIN2 的；要平台认你是英国本地用户，选住宅 IP 的；两样都想要，就得接受“中转 + 落地”两台机器的成本。

**TikTok 英区单账号养号。** 需要住宅 IP，机房 IP 上去大概率零播放。CstoneCloud 的 1 核 1GB 够挂代理跑 App，2 核 2GB 起才适合多开。AkkoCloud 这条线不适合这个用途。

**TikTok 矩阵或直播推流。** 内存至少 4GB，带宽往 500Mbps 看。CstoneCloud 的 4 核 8GB、500Mbps、16TB 那档是这类需求的上限配置，价格也上去了，先算清楚账号收益再买。

**英区流媒体解锁。** BBC iPlayer、ITV Hub、BritBox、英区 Netflix 只认英国 IP，住宅双 ISP 的解锁率明显高于机房 IP。单设备偶尔看，1 核 1GB 就够。

**ChatGPT / Gemini 欧洲出口。** 英国出口的风控比美区宽松，住宅 IP 更稳，机房 IP 也有机会。个人用或 API 调用，最低配足够。

**外贸建站、WordPress、开发测试。** 这类不挑 IP 属性，挑稳定和价格。VM6 Networks 的 2 核 4GB £27 首年、AkkoCloud 的 ¥299/年入门款都能干，区别在于前者续费会涨、后者回国线路更好。

**中转加落地的两段式。** 英国机器只做出出口，配置不用高，1 核 1GB 足够，重点在 IP 干净。中转段另外找香港 CN2 或日本软银的机器。
